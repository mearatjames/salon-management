## 2. Tokens to use (do not invent values)

All from `styles/tokens.css` — already exported.

- **Geometry**: `var(--space-8)` height (32px), `0 var(--space-3)` padding, `var(--space-2)` gap, `var(--radius-md)` corners.
- **Color**: bg `transparent` → hover `var(--accent)`; text `var(--muted-foreground)` → hover `var(--foreground)`; border `var(--border)` → hover `var(--ring)`.
- **Type**: `var(--font-sans)`, `var(--text-sm)`.
- **Divider**: 1px × `var(--space-5)` (20px), `background: var(--border)`.
- **Icon**: `lucide-react` `<Repeat size={16} strokeWidth={1.5} aria-hidden="true" />`.

If you find yourself reaching for a raw px value, stop — Constitution Principle I forbids it.

## 4. New component (`components/lacquer/switch-staff-button.tsx`)

```tsx
"use client";

import { Repeat } from "lucide-react";
import { useFormStatus } from "react-dom";

import { switchStaff } from "@/app/(studio)/actions";

function SubmitButton() {
  const { pending } = useFormStatus();
  return (
    <button
      type="submit"
      className="studio-switch-staff"
      data-slot="switch-staff-button"
      disabled={pending}
      aria-busy={pending || undefined}
    >
      <Repeat size={16} strokeWidth={1.5} aria-hidden="true" />
      Switch staff
    </button>
  );
}

export function SwitchStaffButton() {
  return (
    <form action={switchStaff}>
      <SubmitButton />
    </form>
  );
}
```

Notes:
- `useFormStatus()` lives in `react-dom`, not `react`. It only works inside a `<form>` that has been rendered as a Server Action submitter, hence the inner `<SubmitButton>`.
- `data-slot="switch-staff-button"` is the e2e + unit selector.

## 7. Tests

**Unit** (`tests/unit/auth/operator-menu.test.tsx`):

- Render `<SwitchStaffButton />`. Assert `screen.getByRole("button", { name: /switch staff/i })` exists and its parent is a `<form>` whose `action` prop is `switchStaff`. Assert there is a `<svg>` inside.
- Render `<OperatorMenu><OperatorChip staff={...} /></OperatorMenu>`. Open the dropdown (click the chip). Assert `screen.queryByRole("menuitem", { name: /switch staff/i })` is `null`. Assert `screen.getByRole("menuitem", { name: /sign out/i })` exists.

**e2e** (`tests/e2e/auth.spec.ts`):

Replace each of these patterns (5 occurrences):

```ts
await page.locator("[data-slot='operator-chip']").click();
await page.getByRole("menuitem", { name: /Switch staff/ }).click();
```

with:

```ts
await page.locator("[data-slot='switch-staff-button']").click();
```

Add one new test in the "US3: Switch staff at shift change" `describe` block:

```ts
test("(e) operator chip dropdown contains only Sign out", async ({ page }) => {
  // sign in + pin in as Maya (helpers already in the file)
  await page.locator("[data-slot='operator-chip']").click();
  await expect(page.getByRole("menuitem", { name: /Switch staff/ })).toHaveCount(0);
  await expect(page.getByRole("menuitem", { name: /Sign out/ })).toBeVisible();
});
```
