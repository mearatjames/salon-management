# Lacquer Book — UI Kit (mobile)

The mobile booking experience for clients. Three core screens shown inside an iOS frame:

1. **Discover** — service catalog / featured techs
2. **Booking flow** — pick a tech, time, confirm
3. **Appointment detail** — confirmation + add to calendar

## Files
- `index.html` — interactive shell with iOS frame + bottom-tab nav
- `BookComponents.jsx` — small mobile primitives
- `DiscoverScreen.jsx` / `BookingScreen.jsx` / `AppointmentScreen.jsx`
